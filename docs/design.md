# Шаурма-лавка — дизайн игры

Рабочее название. Площадка: Яндекс Игры, затем VK Games. Графика: минимализм, простые фигуры.

## Идея за 3 секунды
Ты тапаешь по ларьку — продаётся шаурма. Нанимаешь помощников, улучшаешь рецепт, переезжаешь из ларька у метро в кафе, а потом в сеть шаурмичных.

## Игровой цикл
тап по ларьку → деньги → улучшения и помощники → доход идёт сам → офлайн-доход → упор в стену → переезд (престиж) → новый круг быстрее

## Экраны
1. **Ларёк** — сцена с ларьком, тап продаёт шаурму. Покупатели в очереди (кружки), анимация продажи.
2. **Улучшения** — рецепт (доход за тап), помощники (доход в секунду), гриль (скорость), меню (новые позиции).
3. **Переезд** — престиж: ларёк → киоск на рынке → кафе → сеть. Каждый переезд даёт постоянный множитель.
4. **Магазин** — отключение рекламы, «вечный ×2», пакеты денег.

## Экономика
- Цена улучшения растёт в 1,07–1,15 раза за уровень (сейчас 1,15 для рецепта, 1,12 для помощника).
- Офлайн-доход за время отсутствия, не больше 2 часов (потом можно поднимать улучшением).
- Все формулы — в `src/core/economy.ts`, с тестами.

## Монетизация (позже, через SDK Яндекса)
- Видео за награду: удвоить офлайн-доход, буст ×2 на 10 минут.
- Полноэкранная реклама только после переезда.
- Покупки: отключить рекламу, «вечный ×2», пакеты денег.

## Первая версия для релиза
- 3 локации (ларёк, киоск, кафе) и 15–20 улучшений.
- Офлайн-доход и облачное сохранение Яндекса.
- Реклама за награду и после переезда.
- Русский и английский.
