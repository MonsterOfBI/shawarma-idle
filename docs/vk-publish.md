# Как выложить игру в VK Игры

Игра одна и та же для Яндекса и VK: при запуске она сама понимает, где открыта. Во ВКонтакте в адресе есть параметры `vk_app_id` и `sign`, и тогда включается VK Bridge (`src/platform/vk.ts`).

Названия разделов на dev.vk.com иногда меняются. Если что-то выглядит иначе, ищите раздел с похожим смыслом или пришлите скриншот ИИ-помощнику.

## Что работает в VK, а что нет
| | VK |
|---|---|
| Реклама за награду (×2, офлайн-доход, золотой ящик) | да, `VKWebAppShowNativeAds` |
| Полноэкранная реклама после переезда и при возвращении в игру | да |
| Облачное сохранение (с телефона на компьютер) | да, хранилище VK, раз в минуту и при сворачивании |
| Язык игрока | да, из параметра `vk_language` |
| Пауза и звук при сворачивании | да |
| Покупки за голоса | да, после настройки из раздела 5а (сервер на Vercel уже написан, `api/vk-payments.ts`); на iPhone и iPad VK покупки запрещает, там магазин пишет, что недоступно |
| Таблица игроков | да, после настройки из раздела 5а: таблица VK «по очкам» за всё время, кубок открывает окно VK (`api/vk-score.ts`) |

## 1. Создать приложение
1. Откройте https://dev.vk.com, войдите своим аккаунтом ВКонтакте и откройте «Мои приложения».
2. «Создать приложение», тип — **мини-приложение**, категория — **игра**.
3. Название: Шаурма-лавка. Запомните **ID приложения** (число), он есть в настройках.
4. Пока игра не готова, держите её видимой только для себя (в настройках видимости).

## 2. Залить игру на хостинг VK
На компьютере, в папке с игрой:

1. Откройте файл `vk-hosting-config.json` и замените `0` в строке `"app_id"` на ID вашего приложения.
2. Выполните:
   ```bash
   npm install
   npm run deploy:vk
   ```
3. Программа соберёт игру и спросит, публиковать ли. В первый раз она попросит войти во ВКонтакте: откройте ссылку из окна терминала и подтвердите.
4. После загрузки VK сам подставит адреса игры в настройки приложения (для компьютера, телефона и m.vk.com).

Каждую новую версию заливайте той же командой `npm run deploy:vk`.

**Если не хочется ставить ничего на компьютер.** Можно вписать в настройках приложения (поля адреса для всех трёх версий) уже готовую ссылку `https://shawarma-idle.vercel.app`. Это годится для проверки, но для выпуска лучше хостинг VK: он быстрее открывается у игроков в России.

## 3. Проверить внутри ВКонтакте
Открывайте игру только через ВК, не по прямой ссылке: `vk.com/appID` на компьютере и `m.vk.com/appID` на телефоне (вместо ID — номер приложения). Проверьте:
- игра загружается, звук идёт после первого тапа;
- кнопка ×2 показывает рекламу (до одобрения монетизации рекламы может не быть, тогда награда не выдаётся, это нормально);
- закройте игру и откройте снова: деньги и улучшения на месте;
- откройте игру с телефона: прогресс тот же, что на компьютере.

## 4. Страница игры
Картинки лежат в `promo/` (иконка 512×512, обложка 800×470, скриншоты для телефона и компьютера). Если VK попросит другой размер, откройте `promo/art.html?icon` или `promo/art.html?cover` и попросите ИИ-помощника перерисовать под нужный размер.

Название, описание и жанр возьмите из `docs/yandex-publish.md`, раздел 4. Только уберите из описания слова про Яндекс и про недельный рейтинг: в VK таблица одна, за всё время.

## 5. Реклама и выплаты
1. В настройках приложения найдите раздел монетизации и включите рекламу (за награду и полноэкранную). Баннер не нужен.
2. Там же заполните данные для выплат. Статус самозанятого VK поддерживает не для всех продуктов, поэтому проверьте, что он доступен для мини-приложений; если нет, напишите в поддержку разработчиков VK.

## 5а. Покупки за голоса и таблица игроков
Их обслуживает маленький сервер в папке `api/` того же проекта на Vercel, что и игра (`https://shawarma-idle.vercel.app`). Он появляется вместе с обычной выкладкой (сайт на Vercel собирается сам после каждого слияния в ветку `first-version`), отдельно ставить ничего не нужно. Нужно только дать ему два ключа VK и вписать его адрес в VK.

1. **Ключи VK.** В настройках приложения на dev.vk.com найдите «Защищённый ключ» и «Сервисный ключ доступа».
2. **Ключи в Vercel.** Откройте проект `shawarma-idle` на vercel.com → Settings → Environment Variables и добавьте (окружение Production):
   - `VK_APP_SECRET` — защищённый ключ;
   - `VK_SERVICE_TOKEN` — сервисный ключ.

   Затем Deployments → у последней выкладки «Redeploy», чтобы сервер увидел ключи. Ключи никому не показывайте и в чат не присылайте.
3. **Платежи.** В настройках приложения VK, раздел «Платежи»: адрес обратного вызова `https://shawarma-idle.vercel.app/api/vk-payments`. Там же есть тестовый режим: добавьте себя тестировщиком и купите что-нибудь, голоса не спишутся. Товары и цены сервер называет сам:

   | ID | Товар | Цена |
   |---|---|---|
   | `starter_pack` | Стартовый набор | 7 голосов (49 ₽) |
   | `no_ads` | Без рекламы | 14 голосов (98 ₽) |
   | `x2_forever` | Доход ×2 навсегда | 21 голос (147 ₽) |
   | `cash_pack` | Мешок денег | 4 голоса (28 ₽) |
   | `god_pet` | Брейнрот-бог | 21 голос (147 ₽) |

   Цены меняются в двух местах: `api/_vk.ts` (что видит VK) и `src/platform/vk.ts` (что написано на кнопке).
4. **Таблица игроков.** В настройках приложения VK включите таблицу рейтинга типа «по очкам». Игра раз в минуту и при открытии рейтинга отправляет число проданной шаурмы, сервер проверяет подпись запуска и записывает его в VK. Кубок в игре открывает окно рейтинга VK. Недельной таблицы в VK нет.

Если что-то не работает: на vercel.com откройте проект → Logs, там видны ошибки сервера (например, «bad sign» — неверный защищённый ключ, «no token» — не задан сервисный).

## 6. Модерация
Отправьте игру на модерацию как игру. С 26 ноября 2025 года VK Игры и игры Одноклассников проходят одну общую модерацию.

Что уже сделано из частых причин отказа:
- игра вызывает `VKWebAppInit` при запуске;
- реклама за награду только по кнопке игрока, полноэкранная только в паузах (переезд, возвращение в игру) и не чаще раза в 3 минуты;
- звук выключается, когда игру сворачивают;
- интерфейс подстраивается под телефон и компьютер;
- нет упоминаний других площадок в текстах игры.

Если модерация вернёт замечания, скопируйте их ИИ-помощнику целиком.
