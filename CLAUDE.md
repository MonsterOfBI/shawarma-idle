# Шаурма-лавка — правила проекта для ИИ

Idle-кликер про ларёк с шаурмой. Браузерная игра для Яндекс Игр, потом VK Games.
Автор делает игру через вайб-кодинг: немного читает код, работает до 10 часов в неделю.
Дизайн игры описан в `docs/design.md`, план — в `docs/roadmap.md`.

## Стек
- TypeScript, Phaser 3.90 (не Phaser 4: по третьей версии больше примеров и знаний у ИИ), Vite, Vitest.
- `npm run dev` — запуск, `npm test` — тесты, `npm run build` — сборка в `dist/`.

## Структура
- `src/core/` — чистая логика игры (экономика, улучшения, офлайн-доход). Без Phaser, без `window`, без `localStorage`. Всё покрыто тестами в `*.test.ts`.
- `src/scenes/` — сцены Phaser: только отрисовка и ввод. Логику не писать здесь, звать функции из `core`.
- `src/platform/` — адаптер площадки: сохранения, реклама, покупки, язык. Игра обращается к площадке только через интерфейс `Platform`.

## Правила работы
- Одна задача на один запрос. После каждого рабочего шага: `npm test`, `npm run build`, коммит.
- Любое изменение формул экономики сопровождается тестом.
- Состояние игры (`GameState`) — простой JSON. При добавлении поля в `GameState` предусмотреть значение по умолчанию для старых сохранений.
- Никаких сетевых запросов, кроме SDK площадки. Никаких вызовов нейросетей внутри игры (запрещено правилами Яндекс Игр, п. 1.23).
- Графика — минимализм из простых фигур (прямоугольники, круги) в палитре из `StallScene`. Без картинок, пока не решим иначе.
- Тексты для игрока на русском; позже добавим английский через словарь, поэтому строки не разбрасывать по коду без нужды.

## Требования Яндекс Игр, которые надо держать в голове
- Звук выключается, когда вкладка неактивна.
- Интерфейс не разваливается при любом размере окна и на телефоне.
- Сборка до 100 МБ, загружается архивом из `dist/` (поэтому `base: './'` в `vite.config.ts`).
- Рейтинг ниже 30 — снятие с публикации через 3 недели, поэтому реклама только в логичных паузах.
