# Шаурма-лавка — правила проекта для ИИ

Idle-кликер про ларёк с шаурмой. Браузерная игра для Яндекс Игр, потом VK Games.
Автор делает игру через вайб-кодинг: немного читает код, работает до 10 часов в неделю.
Дизайн игры описан в `docs/design.md`, план — в `docs/roadmap.md`.

## Стек
- TypeScript, Phaser 3.90 (не Phaser 4: по третьей версии больше примеров и знаний у ИИ), Vite, Vitest.
- `npm run dev` — запуск, `npm test` — тесты, `npm run build` — сборка в `dist/`, `npm run zip` — сборка и архив `shawarma-idle.zip` для загрузки в консоль Яндекс Игр.

## Структура
- `src/core/` — чистая логика игры. Без Phaser, без `window`, без `localStorage`. Покрыто тестами в `economy.test.ts`.
  - `economy.ts` — `GameState`, тап, покупка, тик, офлайн-доход, переезд, буст, миграция старых сохранений (`normalize`).
  - `upgrades.ts` — таблица из 18 улучшений (тап, помощники, множители). `locations.ts` — 5 локаций с порогами и множителями.
  - `format.ts` — короткие числа (1,2 тыс., 3,4 млн). `sim.ts` — симуляция игрока для тестов баланса.
- `src/scenes/StallScene.ts` — сцена Phaser: ларёк из фигур, очередь покупателей, всплывающие суммы. Только отрисовка и ввод.
- `src/ui.ts` — HTML-интерфейс поверх сцены: деньги, вкладки «Улучшения / Переезд / Магазин», окно офлайн-дохода. Разметка в `index.html`, стили в `src/style.css`.
- `src/game.ts` — контроллер: держит состояние, цикл 10 раз в секунду, сохранение каждые 10 с, реклама, покупки, пауза.
- `src/i18n.ts` — все тексты на русском и английском. Новые строки добавлять только сюда.
- `src/audio.ts` — звуки, синтезированные через Web Audio, без файлов.
- `src/platform/` — адаптер площадки. `platform.ts` — интерфейс `Platform` и локальная версия для браузера; `yandex.ts` — Яндекс SDK (облачные сохранения, реклама, покупки `no_ads`, `x2_forever`, `cash_pack`, язык, пауза).
- `promo/` — иконка, обложка и скриншоты для страницы игры. `art.html` — исходник иконки и обложки.
- `docs/yandex-publish.md` — как выложить игру на Яндекс Игры.

## Правила работы
- Одна задача на один запрос. После каждого рабочего шага: `npm test`, `npm run build`, коммит.
- Любое изменение формул экономики сопровождается тестом.
- Состояние игры (`GameState`) — простой JSON. При добавлении поля в `GameState` предусмотреть значение по умолчанию для старых сохранений.
- Никаких сетевых запросов, кроме SDK площадки. Никаких вызовов нейросетей внутри игры (запрещено правилами Яндекс Игр, п. 1.23).
- Графика — минимализм из простых фигур (прямоугольники, круги) в палитре из `StallScene`. Без картинок, пока не решим иначе.
- Тексты для игрока только через `t()` из `src/i18n.ts`, всегда на двух языках.
- Баланс: тест требует первый переезд за 6–20 минут и каждый следующий за 5–90 минут игры. Меняя цены, запускайте `npm test`.

## Требования Яндекс Игр, которые надо держать в голове
- Звук выключается, когда вкладка неактивна.
- Интерфейс не разваливается при любом размере окна и на телефоне.
- Сборка до 100 МБ, загружается архивом из `dist/` (поэтому `base: './'` в `vite.config.ts`).
- Рейтинг ниже 30 — снятие с публикации через 3 недели, поэтому реклама только в логичных паузах.
