# Шаурма-лавка — правила проекта для ИИ

Idle-кликер про ларёк с шаурмой. Браузерная игра для Яндекс Игр, потом VK Games.
Автор делает игру через вайб-кодинг: немного читает код, работает до 10 часов в неделю.
Дизайн игры описан в `docs/design.md`, план — в `docs/roadmap.md`.

## Стек
- TypeScript, Phaser 3.90 (не Phaser 4: по третьей версии больше примеров и знаний у ИИ), Vite, Vitest.
- `npm run dev` — запуск, `npm test` — тесты, `npm run build` — сборка в `dist/`, `npm run zip` — сборка и архив `shawarma-idle.zip` для загрузки в консоль Яндекс Игр.

## Структура
- `src/core/` — чистая логика игры. Без Phaser, без `window`, без `localStorage`. Покрыто тестами в `economy.test.ts`.
  - `economy.ts` — `GameState`, тап, покупка, тик, офлайн-доход, переезд, буст, миграция старых сохранений (`normalize`).
  - `upgrades.ts` — таблица из 18 улучшений (тап, помощники, множители). `locations.ts` — 7 точек сюжета «из коробки у помойки во дворец шаурмы» с порогами и множителями.
  - `achievements.ts` — 15 достижений, каждое навсегда даёт +3 % к доходу.
  - `pets.ts` — брейнроты-питомцы из ящиков: редкости, шансы, мутации, бонус к доходу (`petMult`), открытие ящика (`openBox`).
  - `daily.ts` — подарок дня на 7 дней. `quests.ts` — три задания с наградами.
  - `brainrots.ts` — 13 итальянских брейнротов: кто на какой точке приходит в очередь, кто работник, кто событие. Коллекция (`met`).
  - `look.ts` — как выглядит ларёк: стадия каждого улучшения (уровни 1, 10, 25, 50, 100) и украшения по сумме уровней.
  - В `economy.ts` также вехи ×2 (`MILESTONES`), криты, эффекты Бомбардиро (`applyGolden`), цена ящика, комбо (серия тапов до ×2), Бомбардиро (`goldenReward`), час пик, покупка пачкой ×1/×10/Макс (`buyN`, `bulkAmount`).
  - `format.ts` — короткие числа (1,2 тыс., 3,4 млн). `sim.ts` — симуляция игрока для тестов баланса.
- `src/scenes/` — только отрисовка и ввод, всё из фигур с тёмной обводкой.
  - `draw.ts` — палитра и `Pen` (заливка + обводка одной командой).
  - `brainrots.ts` — рисунки 13 брейнротов, ноги отдельными кусками для ходьбы.
  - `backdrops.ts` — фоны 7 локаций (помойка, метро, пляж, джунгли, пустыня, площадь, дворец) и то, что ездит или летает по фону.
  - `stall.ts` — ларёк: свой стиль на каждой локации, каждое из 18 улучшений видно на точке и растёт со стадией.
  - `StallScene.ts` — небо со сменой дня и ночи (сутки 8 минут), очередь брейнротов с репликами, Бомбардиро с мешком денег, переезд с затемнением, портреты для коллекции, танцующие питомцы перед ларьком, криты, маскот-зазывала Тунг Тунг (подсказки через `setHints`), тап по всей улице.
- `src/icons.ts` — значки улучшений и наград в виде маленьких SVG.
- `src/ui.ts` — HTML-интерфейс поверх сцены. Игра на весь экран, меню — выдвижная шторка (снизу на телефоне, справа на ПК), по умолчанию закрыта: деньги и бафы, боковые кнопки, вкладки «Улучшения / Брейнроты / Задания / Переезд / Магазин», окна офлайн-дохода, подарка дня и открытия ящика. Разметка в `index.html`, стили в `src/style.css`.
- `src/game.ts` — контроллер: держит состояние, цикл 10 раз в секунду, сохранение каждые 10 с, события (час пик, Бомбардиро, достижения, знакомство с брейнротами), реклама, покупки, пауза.
- `src/i18n.ts` — все тексты на русском и английском. Новые строки добавлять только сюда.
- `src/audio.ts` — звуки и музыка (тарантелла по кругу), синтезированные через Web Audio, без файлов.
- `src/platform/` — адаптер площадки. `platform.ts` — интерфейс `Platform` и локальная версия для браузера; `yandex.ts` — Яндекс SDK (облачные сохранения, реклама, покупки `no_ads`, `x2_forever`, `cash_pack`, язык, пауза).
- `promo/` — иконка, обложка и скриншоты для страницы игры. `art.html` — исходник иконки и обложки, фоном служат кадры игры `scene-*.png`.
- `docs/yandex-publish.md` — как выложить игру на Яндекс Игры.

## Правила работы
- Одна задача на один запрос. После каждого рабочего шага: `npm test`, `npm run build`, коммит.
- Любое изменение формул экономики сопровождается тестом.
- Состояние игры (`GameState`) — простой JSON. При добавлении поля в `GameState` предусмотреть значение по умолчанию для старых сохранений.
- Никаких сетевых запросов, кроме SDK площадки. Никаких вызовов нейросетей внутри игры (запрещено правилами Яндекс Игр, п. 1.23).
- Графика рисуется кодом из фигур в палитре из `src/scenes/draw.ts` и `style.css` (сливовый, крафт, томатный, янтарный). Без картинок-файлов.
- Шрифты Unbounded (заголовки, деньги, цены) и Golos Text (текст) лежат в сборке через `@fontsource`, из интернета ничего не грузится.
- Тексты для игрока только через `t()` из `src/i18n.ts`, всегда на двух языках.
- Баланс: тест требует первый переезд за 6–20 минут и каждый следующий за 5–90 минут игры. Меняя цены, запускайте `npm test`.

## Требования Яндекс Игр, которые надо держать в голове
- Звук выключается, когда вкладка неактивна.
- Интерфейс не разваливается при любом размере окна и на телефоне.
- Сборка до 100 МБ, загружается архивом из `dist/` (поэтому `base: './'` в `vite.config.ts`).
- Рейтинг ниже 30 — снятие с публикации через 3 недели, поэтому реклама только в логичных паузах.
